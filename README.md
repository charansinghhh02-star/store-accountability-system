# 🛒 Offline Store Accountability & Credit Management System

A lightweight, Python-powered Point of Sale (POS) and ledger application built to solve money leakage, untracked inventory, and overdue customer credit for retail store owners.

---

## 🎯 Problems Solved

1. **Accountability & Money Handling:** Tracks opening cash drawers, reconciles daily cash sales, and monitors credit repayments to eliminate discrepancies.
2. **Inventory Control:** Automatically decrements stock levels with every checkout and prevents overselling with live shelf visibility.
3. **Credit (Udhar) Ledger:** Manages customer profiles, enforces borrow limits, records partial/full repayments, and prevents stuck capital.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Frontend:** Streamlit
* **Database:** SQLite
* **Data Processing:** Pandas
